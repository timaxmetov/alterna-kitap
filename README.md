# Alterna Kitap — каталог книг на турецком

Каталог из 310 книг на турецком языке, разложенный по уровням A1–C1: что читать,
где купить и что можно скачать бесплатно.

Сайт — один файл `index.html`, без сборки и зависимостей.

## Что внутри

- **Каталог** — фильтры по уровню, жанру, типу издания и эпохе, поиск, две сетки.
- **Карта каталога** — интерактивная матрица «уровень × жанр» и таймлайн по эпохам.
- **Моя библиотека** — закладки и свои книги, всё в localStorage, с экспортом в файл.
- **Обложки** — подтягиваются из Google Books, Open Library и турецкой Википедии,
  для остальных рисуется своя.
- Светлая и тёмная тема, адаптив, поддержка `prefers-reduced-motion`.

## Разработка

Отдельный `index.html` открывается прямо из файловой системы, но обложки требуют
http, поэтому для локальной работы удобнее поднять любой статический сервер.
